# المدرسة الرمز · التعلم العميق

مخطط دروس ذكي وفق نموذج 5E (60 دقيقة) — عربي (RTL).

## متغيرات البيئة المطلوبة للنشر خارج Lovable (Vercel أو غيره)

| المتغير | الغرض | إلزامي |
| --- | --- | --- |
| `LOVABLE_API_KEY` | مفتاح بوابة الذكاء الاصطناعي: استخراج النواتج، الملء التلقائي، بناء العرض، ورقة العمل، واجب الغائب | نعم — بدونه تفشل كل أزرار الذكاء الاصطناعي |
| `UNSPLASH_ACCESS_KEY` | البحث عن صور توضيحية مشابهة لصفحات الكتاب | اختياري — بدونه يعمل الموقع لكن بحث الصور الخارجية يتوقف |

### طريقة الإضافة على Vercel

1. Project → Settings → Environment Variables.
2. أضف كل متغير باسمه **حرفياً** كما في الجدول أعلاه.
3. حدّد البيئات الثلاث: **Production + Preview + Development**.
4. اضغط Save ثم نفّذ **Redeploy** — المتغيرات لا تُقرأ في نشر قديم.

المفاتيح تُقرأ على الخادم فقط (`process.env`) داخل دوال `createServerFn`،
ولا تُرسل أبداً إلى المتصفح ولا تُسبَق بـ `VITE_`.

## فحص المفاتيح على الخادم

نقطة نهاية جاهزة تُخبرك هل المفاتيح مقروءة على الخادم دون كشف قيمتها:

```
GET /api/public/health
```

الاستجابة:

```json
{
  "ok": true,
  "keys": {
    "LOVABLE_API_KEY": { "present": true, "length": 64 },
    "UNSPLASH_ACCESS_KEY": { "present": false, "length": 0 }
  },
  "checkedAt": "2026-01-01T00:00:00.000Z"
}
```

- `200` = مفتاح الذكاء الاصطناعي موجود.
- `503` = المفتاح غير مضبوط في هذه البيئة (السبب الأشهر لتوقف الأزرار بعد النشر).

## معالجة أخطاء الذكاء الاصطناعي

كل نداء يمرّ عبر `src/lib/ai-gateway.server.ts`:

- يعيد **رمز حالة HTTP حقيقياً** (401/402/429/502/503…) بدل `200` عند الفشل.
- يرسل رسالة عربية مفهومة تُعرض للمستخدم في الواجهة.
- يسجّل في كونسول المتصفح رمز الحالة ونص الاستجابة الخام عبر `reportAiError`.
- لا يُبتلع أي فشل صامتاً في أي موضع.
